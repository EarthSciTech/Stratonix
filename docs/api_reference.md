# Stratonix API reference

Generated by `tools/gen_api_reference.py` from the header comments (the same comments Doxygen reads with `docs/Doxyfile`).
Namespaces: `stratonix` (C++ library), C functions prefixed `stx_` (stable C API).

## include/stratonix/checks/checks.hpp

- `(file)`  
  Checks that fail a build, each with a stated tolerance, plus closure reporting.
- `struct CheckResult`  
  One check outcome.
- `struct GridProducts`  
  Grids and properties of a description's grid block (stage 3B, STX-TN-12), computed once and shared by the checks (C23 to C25), the exports and the figures.
- `const repr::TetGrid& tets() const;`  
  The tetrahedral grid, built when first asked for: only the export that writes it needs it (I-050; six tetrahedra per cell are about 215 bytes per cell).
- `int model_unit_of(const desc::Description& d, const Model& m, const std::string& unit);`  
  Model unit index of a description unit (by its top and base horizons), or -1.
- `GridProducts make_grid_products(const desc::Description& d, const Model& m);`  
  Everything the grid block asks for; requires d.grid.present.
- `class CheckContext`  
  Shared, lazily computed representations used by checks (and reused by exports/figures).
- `bool timeline_checks = true;`  
  False when checking a state of a timeline (C17 and C18 then belong to the full model).
- `double tolerance(const std::string& key, std::string* source) const;`  
  Tolerance from the description or the built-in default; `source` receives where it came from.
- `const GridProducts* grid_products();`  
  Grid products of the description's grid block (nullptr without one); computed once.
- `repr::FaultedSurfaceCache* surfaces() { return surfaces_.get(); }`  
  The faulted surfaces of this model, shared with the figures and exports of the build.
- `void add_grid_property(repr::CellProperty p);`  
  Stage 4B: add a cell property computed by the pipeline (P32, P32_DFN) before the checks run.
- `const PotentialFieldResult* potential_fields = nullptr;`  
  Stage 4A: station misfits of the geophysics block (C29), set by the pipeline; nullptr = none.
- `const struct VolumetricResult* volumetric = nullptr;`  
  Stage 4B: the volumetric restoration of the restoration block (C31), set by the pipeline.
- `struct BasinResults`  
  Stage 4B: heat, pressure and fracture-network results for C32 to C34, set by the pipeline.
- `struct WellDataResults`  
  Stage 4C (STX-TN-16 section 6): well data (C35) and age consistency (C38), set by the pipeline.
- `struct TimeDepthResults`  
  Stage 4C: time-depth ties after conversion (C36), set by the pipeline.
- `struct GeostatResults`  
  Stage 4D: geostatistical properties (C39 conditioning, C40 statistics), set by the pipeline.
- `const ContactGraph& contact_graph();`  
  Stage 4A: the contact graph (C26, topology.json), computed once at topology_spacing().
- `double topology_spacing() const;`  
  outputs.voxel_spacing (x) when given, else max(surface spacing, largest extent / 64).
- `class Check : public registry::PluginBase`  
  Check plugin interface.
- `CheckReport run_checks(CheckContext& ctx);`  
  Run every registered check (in name order) and return the report.
- `struct BalanceRow`  
  Line-length and area balance of a section (stage 2E, STX-TN-09 section 3): each horizon's bed length and each unit's area in the present section against the same material restored (faults undone by their own inverses). One row per horizon ("line length") and per unit ("area").
- `void register_check_plugins();`  
  Register this layer's plugins.
- `repr::FaultRockInput fault_rock_input(const desc::Description& d, const Model& m);`  
  Fault-rock and stress inputs from a description (stage 2F, STX-TN-10), in SI units.
- `repr::StressInput stress_input(const desc::Description& d, const Model& m);`  
  With the description's mechanical stratigraphy (stage 4B) mapped onto the model's units.

## include/stratonix/checks/manifest.hpp

- `(file)`  
  Run manifest: inputs with SHA-256, resolved description, build information, outputs. Timestamps appear only in the manifest, so every other output is byte-identical between runs.
- `bool portable = false;`  
  Portable manifests leave out the compiler, platform and build type, so the same package built on different machines differs only by the timestamp.
- `static Manifest from_description(const desc::Description& d, const std::string& command);`  
  Fill description, inputs and build information from a description.
- `void add_outputs(const std::filesystem::path& root, const std::string& role_default = "output");`  
  Add every regular file under `root` (except the manifest itself) as an output, sorted.
- `std::string utc_timestamp();`  
  Current UTC time as ISO 8601 (seconds).
- `std::vector<std::string> verify_manifest(const std::filesystem::path& manifest_file);`  
  Verify a manifest.json against the files in its folder. Returns a list of problems (empty = ok).

## include/stratonix/core/crs.hpp

- `(file)`  
  Coordinate reference system record. Transformations need PROJ (optional build).
- `struct CrsInfo`  
  Coordinate reference system of a model. A local frame has epsg == 0 and no WKT.
- `std::string label() const`  
  One-line label used in figure footers and README files.
- `bool crs_reprojection_available();`  
  True when the library was built with PROJ (reprojection available).
- `struct CrsOperation { std::string name, method; double accuracy = -1; };`  
  Stage 4C (STX-TN-16 section 2.4): a transformation between two CRS chosen by PROJ, with its name, method and stated accuracy (negative when PROJ states none). Refused without PROJ.
- `void apply(std::vector<double>& x, std::vector<double>& y, std::vector<double>& z) const;`  
  Transform (x, y, z) in place; x, y in the CRS's axis order as easting, northing (or longitude, latitude in degrees for a geographic CRS).

## include/stratonix/core/grid.hpp

- `(file)`  
  Regular 2D grids (unrotated in v1) with contiguous storage, x fastest.
- `struct GridSpec`  
  Geometry of a regular grid: node (i, j) is at (x0 + i*dx, y0 + j*dy).
- `static GridSpec covering(const Domain& d, double spacing)`  
  Grid covering a domain at a spacing (node-centred, includes both edges).
- `struct Grid2D`  
  Scalar field on a regular grid. Undefined nodes hold NaN.

  Bilinear interpolation; NaN if outside or if any corner is undefined.
- `double sample_clamped(double x, double y) const`  
  As sample(), but outside the grid the nearest edge value is held (constant extrapolation).

## include/stratonix/core/linalg.hpp

- `(file)`  
  Dense linear solvers for interpolation systems (Eigen is not available in every build; these are small, dependency-free and deterministic).
- `void solve_dense_reference(std::vector<double>& A, std::vector<double>& b, std::size_t n);`  
  Solve A x = b for a dense n x n row-major matrix by Gaussian elimination with partial pivoting. Reference implementation: plain loops, the specification for the optimised solver. A and b are overwritten; the solution is returned in b. Throws Error(Build) if A is singular.
- `void solve_dense_blocked(std::vector<double>& A, std::vector<double>& b, std::size_t n, std::size_t block = 64);`  
  Same result by a blocked right-looking LU factorisation with partial pivoting whose trailing updates run in parallel (fixed chunks, so the result does not depend on the thread count). Pivot choices equal the reference's up to rounding; parity is tested.
- `void solve_dense(std::vector<double>& A, std::vector<double>& b, std::size_t n, std::size_t threshold = 256);`  
  Solve with the optimised solver when optimised_kernels() is on and n >= threshold, otherwise with the reference solver.
- `void solve_dense_multi(std::vector<double>& A, std::vector<double>& B, std::size_t n, std::size_t m);`  
  Solve A X = B for m right-hand sides (B row-major n x m), by the reference elimination with partial pivoting. A and B are overwritten; the solutions are returned in B. Used where entries of the inverse are needed (leave-one-out errors, stage 3A).
- `void symmetric_eigen3(const double a[9], double values[3], double vectors[9]);`  
  Eigen-decomposition of a symmetric 3 x 3 matrix by Jacobi rotations: eigenvalues ascending, eigenvectors as columns (v[3*row + col]).

## include/stratonix/core/roots.hpp

- `(file)`  
  Bracketed scalar root finding (Illinois variant of regula falsi).
- `template <class F> double illinois(F&& f, double a, double b, double fa, double fb, double xtol = 1e-9, double ftol = 0, int maxit = 200)`  
  Root of f in [a, b] given f(a) = fa and f(b) = fb of opposite signs. Converges superlinearly and never leaves the bracket. Stops when |f| < ftol or the bracket is shorter than xtol.
- `template <class F> double expand_and_solve(F&& f, double x0, double step, double max_span, double xtol = 1e-9)`  
  Expand a bracket around x0 (step, doubling) until f changes sign, then solve. Returns NaN if no sign change is found within `max_span` of x0.

## include/stratonix/core/util.hpp

- `(file)`  
  SHA-256, locale-independent number formatting, files, threads, version, logging.
- `std::string sha256_hex(std::string_view data);`  
  Hex SHA-256 of a byte string.
- `std::string sha256_file(const std::filesystem::path& p);`  
  Hex SHA-256 of a file's contents.
- `std::string fmt_fixed(double v, int decimals);`  
  Fixed notation with `decimals` digits after the point ("-0.000" is normalised to "0.000").
- `std::string fmt_shortest(double v);`  
  Shortest round-trip representation.
- `double parse_double(std::string_view s);`  
  Parse a double with '.' as decimal separator; throws Error on failure.
- `void write_file(const std::filesystem::path& p, std::string_view data);`  
  Write bytes exactly (binary mode, so '\n' stays '\n' on Windows). Creates parent folders.
- `std::string portable_path(const std::filesystem::path& p, const std::filesystem::path& base = {});`  
  Path with forward slashes, relative to base if possible (used in manifests).
- `void set_thread_count(unsigned n);`  
  Set the number of worker threads (0 = hardware concurrency). Results never depend on it.
- `void parallel_for(std::size_t n, std::size_t chunk, const std::function<void(std::size_t, std::size_t)>& fn);`  
  Run fn(begin, end) over [0, n) in fixed chunks of `chunk` items. The chunking does not depend on the thread count, and each index is processed by exactly one call, so results are identical for any number of threads. Exceptions from workers are rethrown on the caller.
- `void set_optimised_kernels(bool on);`  
  Global switch used by tests: when false, optimised kernels fall back to reference versions.
- `std::size_t peak_rss_bytes();`  
  Peak resident memory of this process in bytes (0 if unknown on this platform).
- `std::size_t current_rss_bytes();`  
  Memory in use now (resident set / working set) in bytes; 0 where unknown.
- `std::string xml_escape(std::string_view s);`  
  Escape for XML/SVG text and attributes.
- `std::string json_escape(std::string_view s);`  
  Escape for JSON strings (without quotes).

## include/stratonix/core/well.hpp

  Stage 4C: a well from positions computed by a stated survey method: measured depth and (north, east, TVD) offsets from the head, TVD positive down.
- `Vec3 at_md(double md) const;`  
  Point at a measured depth (interpolated along the path; vertical beyond total depth).
- `const Polyline& points() const { return pts_; }`  
  Path points (x, y, z) from the head to total depth.
- `Vec3 at_elevation(double z) const;`  
  Horizontal position at an elevation (interpolated along the path).
- `double md_at_elevation(double z) const;`  
  Measured depth at a point index-interpolated along the path (for tops reports).

## include/stratonix/desc/description.hpp

- `(file)`  
  Typed, validated model description (schema version 1) with evidence on every parameter.
- `enum class Evidence { Measured, Interpreted, Calibrated, Upscaled, LiteratureDerived, Assumed, UserInstruction };`  
  Evidence class carried by every parameter.
- `const char* evidence_plain(Evidence e);`  
  Plain-words description used in README files ("assumed by the modeller", ...).
- `struct Param`  
  A labelled parameter: value(s), unit, evidence class and source.
- `struct WellLogDesc { std::string file, frame, index; std::vector<std::string> curves; std::filesystem::path resolved; };`  
  Stage 4C (STX-TN-16 section 1): log files of a well, read as delivered.
- `struct WellAgeDesc { std::string kind, name, timescale, source; Param depth, depth_base, age, sigma; };`  
  Stage 4C: an age datum in a well (TVD below the model datum, positive down, as the tops).
- `std::string survey_method, azimuth_reference, survey_file;`  
  stage 4C (rule F44): the survey's calculation method and azimuth reference; both empty for a trajectory written as in v3 (minimum curvature, grid azimuths)
- `struct PickPerturbation { bool present = false; Param sigma, correlation_length; std::uint64_t seed = 0; } surface_perturbation;`  
  stage 4C (STX-TN-16 section 3): one realisation of the pick uncertainty of a surface in time
- `struct SeriesDesc`  
  Stratigraphic series (STX-TN-07 section 1): consecutive horizons, youngest first.
- `struct GrowthDesc { std::string onset, end; bool present() const { return !onset.empty(); } };`  
  Growth strata (STX-TN-07 section 4): movement between onset and end.
- `struct EventDesc`  
  Event of the timeline (STX-TN-09 section 1).
- `struct FaultRockDesc`  
  Fault rock and stress (STX-TN-10).
- `struct SaltBodyDesc`  
  Salt (STX-TN-08 section 1).
- `struct CompactionUnitDesc`  
  Compaction (STX-TN-08 section 3).
- `struct UnitDesc { std::string name, top, base, role, color, label; Param clay_fraction; };`  
  A unit between consecutive horizons; top "model_top" / base "model_base" name the units above the first and below the last horizon.
- `struct TipDesc { std::string rule; std::string horizon, unit; Param offset, fraction, depth; std::string stratigraphy = "fault_frame"; };`  
  Tip rule. stratigraphy: "fault_frame" (default) places the tip on the stratigraphy as displaced by older faults; "unfaulted" on the stratigraphy before any faulting.
- `struct SheetAnnotationDesc { std::string type, text, horizon, fault, side = "footwall", well, completion; Param at, text_at; };`  
  Section sheet (presentation page) settings.
- `struct ImplicitData { std::string input, kind, format, horizon; Param uncertainty; };`  
  Data-conditioned (implicit) structure: data inputs and interpolation settings.
- `struct FitParameterDesc { std::string path; Param min, max; };`  
  Hybrid conditioning (stage 3A, STX-TN-11 section 4): parameters of the description fitted to data.
- `struct GridZoneDesc { std::string unit, layering = "proportional"; Param layers, layer_thickness; };`  
  Grids and properties (stage 3B, STX-TN-12 section 10).
- `struct Upscaled { std::string curve, method, name; Param min_valid; };`  
  stage 4C: logs upscaled to the cells the wells pass through
- `struct VariogramDesc`  
  stage 4D (STX-TN-17 section 1): properties simulated by geostatistics
- `struct RestorationUnitDesc { std::string unit; Param young, poisson; };`  
  Restoration (stage 4B, STX-TN-15 section 4): volumetric restoration of the whole model to a horizon (decision 18) and the bed-length limit of C31.
- `struct BackstripStepDesc { std::string horizon; Param water_depth, sea_level; };`  
  Backstripping (STX-TN-15 section 4.4).
- `struct ErodedSectionDesc { std::string name, well, unconformity, log; Param surface_porosity, decay, vitrinite_estimate; };`  
  Eroded-section estimates from porosity logs (STX-TN-15 section 4.5).
- `struct MechanicsUnitDesc { std::string unit; Param young, poisson, ucs, biot; };`  
  Mechanical stratigraphy and tectonic strain (stage 4B, STX-TN-15 section 5.3, I-033).
- `struct FractureUnitDesc { std::string unit; Param p32_0, a_k, a_e, p32_max; };`  
  Fracture intensity per unit and discrete fracture networks (STX-TN-15 sections 5.1, 5.2).
- `struct HeatUnitDesc { std::string unit; Param conductivity, heat_production; };`  
  Heat (STX-TN-15 section 6.1).
- `struct PressureUnitDesc { std::string unit, law; Param k0, b, phi0; };  ///< exponential: k0 exp(b (phi - phi0)); kozeny_carman: k0 (phi/phi0)^3 ((1-phi0)/(1-phi))^2 struct PressureDesc { bool present = false; Param viscosity, rho_water, rho_grain; std::vector<PressureUnitDesc> units; };`  
  Overpressure from disequilibrium compaction (STX-TN-15 section 6.2).
- `struct GeobodyDesc`  
  Geobodies (stage 4B, STX-TN-15 section 3.3): channel belts and lobes placed inside a unit in geological-time coordinates, so they follow the unit's deformation.
- `struct BodyDesc`  
  Bodies (stage 4B, STX-TN-15 section 1): salt sheets, sills, saucer sills, dykes, injectites.
- `struct GeophysicsUnitDesc { std::string unit; Param density, susceptibility; };`  
  Gravity and magnetics (stage 4A, STX-TN-14 section 7).
- `struct UncertainParamDesc { std::string path, distribution; Param mean, sd, min, max, mode, values, weights; };`  
  Uncertainty (stage 3C, STX-TN-13 section 6).
- `struct PickUncertaintyDesc { std::string horizon; Param sigma, correlation_length; };`  
  stage 4C (STX-TN-16 section 3): pick and velocity uncertainty carried into depth
- `struct Sensitivity { bool present = false; std::string method; Param base_samples, bootstrap, confidence; } sensitivity;`  
  stage 4D (STX-TN-17 section 3): total-effect sensitivity by a Saltelli design
- `struct Description`  
  A complete, validated model description.
- `struct VelocityPerturbation { bool present = false; Param v0_sigma, k_sigma, correlation_length; std::uint64_t seed = 0; };`  
  stage 4C (STX-TN-16 section 2.3, decision 23): layer-cake velocity model one realisation of a layer's velocity uncertainty (STX-TN-16 section 3; written by the ensemble)
- `struct SeismicDesc { bool present = false; std::string input, domain; int il = 0, xl = 0, x = 0, y = 0; } seismic;`  
  stage 4C: a SEG-Y volume for sampling and display
- `struct MapSource { std::string input, format, layer, field; };`  
  stage 4C (section 2.5): a model from a geological map
- `std::vector<const EventDesc*> events_for(const std::string& type, const std::string& ref) const;`  
  Events referring to a fault, primitive or body (stage 2E).
- `int series_of(int h) const;`  
  Series of horizon h (index into series), -1 when no series are given.
- `std::vector<const Param*> all_params() const;`  
  Every parameter present in the description (for the parameters table and manifest).
- `const Param* param_by_name(const std::string& path) const;`  
  The parameter named by a path with names (faults.F1.throw.max, structure.primitives.A1.relief.H1, stratigraphy.horizons.H2.depth, wells.W1.head), or null.
- `struct ValidationReport`  
  Result of validation: issues with field paths and rule identifiers.
- `const std::string& schema_v1_text();`  
  The embedded JSON Schema (version 1) as text.
- `void migrate(Node& doc);`  
  Upgrade a document to the current schema version in place. Throws on unknown versions.
- `ValidationReport validate_description(const std::filesystem::path& file, Description* out = nullptr);`  
  Parse, migrate, validate (schema and semantic rules) and type a description. Never throws for validation problems: they are returned in the report.
- `Description load_description(const std::filesystem::path& file);`  
  As validate_description, but throws Error(Validation) with the report text if invalid.

## include/stratonix/engines/bodies.hpp

- `struct SheetBody`  
  An allochthonous salt sheet: footprint polygon (x, y), flat base, thickness tapering linearly to zero over `taper` metres inside the footprint edge.
- `double thickness_at(double x, double y) const;`  
  thickness at (x, y): 0 outside the footprint
- `double sheet_volume(const SheetBody& s, double spacing);`  
  Volume of a sheet integrated on a grid of the given spacing (m^3).
- `struct SillBody`  
  A circular sill with the elliptical crack profile h(r) = h0 sqrt(1 - r^2 / a^2) and the forced fold above it, w(r) = w0 (1 - r^2 / a^2)^2, with w0 set by volume and the accommodation factor.
- `struct InjectiteSpec`  
  Sand injectite complex sourced from a parent unit (sheets seeded and reproducible).
- `struct BodyReport`  
  A body placed in a model (capability "bodies" of a model with bodies).
- `ModelPtr wrap_bodies(const desc::Description& d, ModelPtr base, BuildLog& log);`  
  Wrap a built model with the description's bodies (STX-TN-15 section 1). Bodies take the unit query where they occupy a point (youngest first); sills lift their roof and salt sheets their overburden (the host is evaluated at the undeformed position); restoration removes the bodies. Throws Error(Build) for a body that crosses a rule (for example a younger fault crossing it).

## include/stratonix/model/model.hpp

- `(file)`  
  The model interface every engine implements, and the flat-layers reference model. Every model, whatever builds it, answers the same questions: which unit and which fault block is at a point, what is the value of each horizon's scalar field there, and (through the representation layer) where its surfaces are. Sections, exports and checks use only this interface, so they work unchanged for the parametric engine (v1) and an implicit engine (v2).
- `enum class EvidenceBasis { Design, Interpreted };`  
  Evidence basis of a whole model, written into every exported file.
- `using BlockCode = std::uint64_t;`  
  Fault-block code: bit f set when the point is on the hanging-wall side of fault f.
- `std::string termination;`  
  Designed termination inside the model (stage 2C): "truncation", "onlap", "pinch-out", "clinoform", or empty.
- `struct FaultInfo`  
  Approximate plane and extent of a fault, used by extractors to locate its surface.
- `std::vector<std::pair<double, double>> profile;`  
  Curved faults: the profile in the dip plane, (u, depth) with u the horizontal distance from the reference point along the dip direction; the plane fields above are then its chord.
- `std::vector<std::string> relations;`  
  Recorded relations with other faults: "abuts F", "splay of F" (abutting with transfer), "relays with F".
- `bool overlapping = false;`  
  True when the hanging wall can override the footwall (reverse sense, or slip with an upward component): a vertical can then meet the same horizon in two blocks.
- `struct ModelInfo`  
  Description of a model, independent of the engine.
- `std::vector<std::string> provenance;`  
  Data the model was conditioned on, one line per input with its evidence class and source (empty for purely parametric models). Carried into export READMEs and packages.
- `struct DataMisfit`  
  Misfit of a data-conditioned model at one data point (capability "data_misfit" returns a const std::vector<DataMisfit>*).
- `struct StratigraphyQuery`  
  Stratigraphic queries a model may offer through capability("stratigraphy") (stage 2C, STX-TN-07): whether horizon h is clamped by a series relation at a restored-frame (x, y), so it has no top there.
- `virtual std::string termination_at(int unit, double x, double y, double radius) const = 0;`  
  Kind of termination of model unit `unit` near restored (x, y) within `radius`: "truncation", "onlap", "pinch-out", "clinoform", or empty where the unit is present.
- `struct ColumnQuery`  
  The restored-frame stratigraphic column a model may offer through capability("column") (stage 2F, STX-TN-10): the elevation of every horizon at restored (x, y), top first.
- `struct PorosityQuery`  
  Compaction porosity a model may offer through capability("porosity") (stage 3B, STX-TN-12 section 2): the mean porosity of model unit `unit` between two present-day points on a vertical (top above base), from the unit's compaction law over their restored depths below the surface. NaN when the unit has no compaction law.
- `enum EvalFields : unsigned { kEvalUnit = 1u, kEvalBlock = 2u, kEvalScalars = 4u, kEvalAll = 7u };`  
  Which fields evaluate() should fill.
- `struct EvalResult`  
  Results of evaluate(), structure of arrays. scalar is horizon-major: scalar[h * n + i].
- `struct FaultEval`  
  Results of evaluate_fault().
- `class Model`  
  The model interface. Implementations are immutable after construction; all methods are thread-safe and write only to caller-owned outputs.
- `virtual void evaluate(std::span<const Vec3> pts, unsigned fields, EvalResult& out) const = 0;`  
  Evaluate unit index, block code and/or horizon scalar fields at points. Scalar convention: zero on the horizon, positive above it, approximately metres nearby.
- `virtual void scalar_in_block(std::span<const Vec3> pts, BlockCode block, int horizon, std::span<double> out) const = 0;`  
  Scalar field of one horizon as seen from a given fault block (extended beyond the block).
- `virtual void evaluate_fault(int fault, std::span<const Vec3> pts, FaultEval& out) const = 0;`  
  Distance to, extent coordinate on, and displacement of fault `fault` at points.
- `virtual void evaluate_fault_geometry(int fault, std::span<const Vec3> pts, FaultEval& out) const { evaluate_fault(fault, pts, out); }`  
  Distance and extent only (displacement left at 0): what locating a fault surface needs. The values are those evaluate_fault() returns; engines that can skip the displacement do.
- `virtual void restore(std::span<const Vec3> pts, std::span<Vec3> out) const = 0;`  
  Positions in the restored (unfaulted) frame.
- `virtual const void* capability(std::string_view name) const { (void)name; return nullptr; }`  
  Optional engine-specific capability by name (nullptr if not provided).
- `class FlatLayersModel final : public Model`  
  Reference implementation: flat, horizontal, unfaulted layers. It is the simplest model that passes the interface suite, and documents the expected behaviour of every call.
- `FlatLayersModel(ModelInfo info, std::vector<double> horizon_z);`  
  horizon_z: elevations of the horizons, top to base (strictly decreasing).
- `inline int unit_from_scalars(const double* s, std::size_t stride, std::size_t nh)`  
  Unit index from horizon scalars at one point: the number of horizons the point lies below.
