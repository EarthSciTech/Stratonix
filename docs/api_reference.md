Generated by `tools/gen_api_reference.py` from the header comments (the same comments Doxygen reads with `docs/Doxyfile`).
Namespaces: `stratonix` (C++ library), C functions prefixed `stx_` (stable C API).

## include/stratonix/checks/manifest.hpp

## include/stratonix/core/linalg.hpp

- `(file)`  
  Dense linear solvers for interpolation systems (Eigen is not available in every build; these are small, dependency-free and deterministic).
- `void solve_dense_reference(std::vector<double>& A, std::vector<double>& b, std::size_t n);`  
  Solve A x = b for a dense n x n row-major matrix by Gaussian elimination with partial pivoting. Reference implementation: plain loops, the specification for the optimised solver. A and b are overwritten; the solution is returned in b. Throws Error(Build) if A is singular.
- `void solve_dense_blocked(std::vector<double>& A, std::vector<double>& b, std::size_t n, std::size_t block = 64);`  
  Same result by a blocked right-looking LU factorisation with partial pivoting whose trailing updates run in parallel (fixed chunks, so the result does not depend on the thread count). Pivot choices equal the reference's up to rounding; parity is tested.
- `void solve_dense(std::vector<double>& A, std::vector<double>& b, std::size_t n, std::size_t threshold = 256);`  
  Solve with the optimised solver when optimised_kernels() is on and n >= threshold, otherwise with the reference solver.
- `void symmetric_eigen3(const double a[9], double values[3], double vectors[9]);`  
  Eigen-decomposition of a symmetric 3 x 3 matrix by Jacobi rotations: eigenvalues ascending, eigenvectors as columns (v[3*row + col]).

## include/stratonix/core/roots.hpp

- `(file)`  
  Bracketed scalar root finding (Illinois variant of regula falsi).
- `template <class F> double illinois(F&& f, double a, double b, double fa, double fb, double xtol = 1e-9, double ftol = 0, int maxit = 200)`  
  Root of f in [a, b] given f(a) = fa and f(b) = fb of opposite signs. Converges superlinearly and never leaves the bracket. Stops when |f| < ftol or the bracket is shorter than xtol.
- `template <class F> double expand_and_solve(F&& f, double x0, double step, double max_span, double xtol = 1e-9)`  
  Expand a bracket around x0 (step, doubling) until f changes sign, then solve. Returns NaN if no sign change is found within `max_span` of x0.

## include/stratonix/engines/faults.hpp

- `(file)`  
  The fault network: planar faults with horizon-relative tips, throw profiles, slip modes (kinematics), hanging-wall displacement fields, ages, abutting and the frame rule. The network is its own object. Once its tips are resolved it no longer needs the horizons, so another engine (v2 implicit) can reuse it unchanged.
- `double profile_value(ProfileType p, double taper, double t);`  
  Normalised throw profile on t in [0, 1]: zero at both ends, 1 at t = 0.5.
- `class Kinematics : public registry::PluginBase`  
  Kinematics plugin: direction of hanging-wall displacement per unit (vertical) throw.
- `virtual Vec3 slip_vector(const Vec3& dd, double dip) const = 0;`  
  dd: unit down-dip vector; dip in radians. Returned vector has vertical component -1.
- `class HangingWallField : public registry::PluginBase`  
  Hanging-wall field plugin: scales the displacement with distance from the fault.
- `virtual double scale(double sigma, double next, double influence) const = 0;`  
  sigma: distance from the plane on the moving side (>= 0); next: distance along the fault normal to the next fault plane (infinity if none); influence: influence distance.
- `struct TipRule`  
  Rule placing a fault tip relative to the stratigraphy.
- `struct Fault`  
  One fault with resolved geometry.
- `bool layered = false;`  
  Hanging wall "layer_rigid": every layer moves as a rigid slab by the throw where that layer meets the fault (in the fault's frame), so the displacement of a point depends on its stratigraphic level, not on its elevation.
- `double layer_b(double s, double a) const;`  
  Down-dip position where stratigraphic level s (horizon index, fractional inside units; -1 domain top, nh domain base) meets the plane at strike position a.
- `void profile_coords(const Vec3& p, double& a, double& b) const`  
  Profile coordinates of a point: strike position, and the down-dip position of the fault point at the same elevation. A hanging-wall point therefore takes the displacement of the fault where its own elevation meets the fault (equal to ab() on the plane).
- `void tips(double a, double& bu, double& bl) const;`  
  Effective tip positions at strike position a (elliptical tip line applied).
- `double throw_at(double a, double b) const;`  
  Vertical throw (signed, + normal) at plane coordinates; 0 outside the tip line.
- `double extent_coord(double a, double b) const;`  
  Extent coordinate: <= 1 inside the tip line.
- `class FaultNetwork`  
  Faults, their relations and the frame rule.
- `FaultNetwork(const desc::Description& d, const Structure& st, BuildLog& log);`  
  Resolve faults from a description against the restored structure.
- `Vec3 restore(const Vec3& p, BlockCode* block, const BlockCode* forced = nullptr) const;`  
  Restore a present-day point through all faults (youngest first). If `forced` is given, the side of each fault is taken from it instead of the point's position. Returns the restored position; writes the block code if `block` is not null.
- `Vec3 to_fault_frame(const Vec3& p, int f) const;`  
  Position of p in the frame of fault f (restored through faults younger than f).
- `Vec3 relative_displacement(int f, const Vec3& q, bool* active = nullptr) const;`  
  Relative hanging-wall displacement of fault f for material whose restored position is q (in f's frame), and whether the fault is active there (abutting).
- `Vec3 undo(int f, const Vec3& q, int sgn, double* tau = nullptr) const;`  
  Undo fault f for a present position q (in f's frame) on its moving side. sgn = +1 when the hanging wall moves, -1 when the footwall moves. Solves q0 = q - sgn * slip * tau(q0), where tau = throw x hanging-wall scale at the restored position q0 (bracketed, Illinois method), so the throw at a horizon is read where the horizon meets the fault before faulting and does not depend on which block the frame holds fixed. Returns q0; writes tau if asked.
- `bool cannot_move(int f, const Vec3& q) const;`  
  True when fault f provably cannot displace material whose present position is q (the restored position stays outside the active region for any displacement up to tmax). Then undo() would return q exactly, so skipping it changes nothing.
- `Vec3 restore_from_frame(const Vec3& q, int f, bool hanging_wall) const;`  
  Restore a point given in fault f's frame, on the stated wall of f, through f and the faults older than it (used to measure throw in the fault's own frame).
- `const std::vector<int>& young_to_old() const { return order_; }`  
  Ages, youngest first.
- `double layer_displacement(int f, const Vec3& p, bool* active = nullptr) const;`  
  Layer-rigid networks: displacement magnitude of fault f for the material at present position p (its level found by restoring p through every fault).
- `bool layered() const { return layered_; }`  
  True when the faults use layer-rigid hanging walls (all of them do, or none).
- `double strat_coord(const Vec3& r) const;`  
  Stratigraphic coordinate of a restored point: horizon index, fractional inside a unit (-1 at the domain top, nh at the domain base, linear in metres / 1000 beyond them).
- `Vec3 chain(const Vec3& q, std::size_t r0, std::size_t r1, double s, BlockCode* code, const BlockCode* forced, int first) const;`  
  Layer-rigid restoration of q through the faults of ranks [r0, r1) for material at level s. first: 0 evaluate the side of the first fault; +1 / -1 move it as hanging wall / footwall (undo semantics); +2 / -2 take its side as hanging wall / footwall and respect the frame.
- `double solve_layer(const Vec3& q, std::size_t r0, const BlockCode* forced, int first) const;`  
  Level s of the material at q such that restoring it through ranks [r0, end) lands on level s.
- `void register_fault_plugins();`  
  Register built-in kinematics and hanging-wall plugins (part of register_engine_plugins()).

## include/stratonix/engines/implicit.hpp

- `(file)`  
  Data-conditioned (implicit) structure builder: a stratigraphic scalar field interpolated from interface points, orientations and well tops by Hermite radial basis functions (cubic kernel, linear drift), with faults from the v1 fault network. The field is interpolated in the restored frame; data are restored through the faults and the field is re-solved until the fault tips (which refer to the horizons) and the data agree. The result is a model behind the same interface as the parametric engine, so every section, export, check and package command works on it unchanged.
- `class RbfField`  
  Hermite RBF interpolant s(x) = sum_i a_i phi(x - x_i) - sum_j beta_j e_j . grad phi(x - y_j) + c0 + c . x with phi(d) = |d|^3, fitted to values at interface points x_i and, at each orientation, to two tangent constraints e . grad s = 0 (the direction of the gradient, not its magnitude).
- `RbfField(std::vector<Value> values, std::vector<Gradient> grads, double nugget, Vec3 centre, double scale, double vertical_stretch = 1.0);`  
  Fit. nugget (m) is added to the diagonal of the value rows (0 = exact interpolation). Coordinates are centred and scaled by `scale` internally for conditioning. vertical_stretch > 1 stretches z before the kernel is applied (anisotropy: horizons vary slowly laterally compared with the spacing of the horizons).
- `struct FittedPlane { Vec3 centroid, normal; double strike = 0, dip = 0, rms = 0; std::size_t points = 0; };`  
  Plane fitted to fault sticks: centroid, unit normal pointing up, strike and dip (radians, right-hand rule: dip direction = strike + 90 degrees) and RMS distance of the points.
- `class ImplicitModel final : public Model`  
  The model returned by the implicit builder: a parametric model whose horizons are the implicit surfaces, plus provenance and the misfit at every data point.
- `const void* capability(std::string_view name) const override;`  
  "structure", "faults" (as the parametric engine), "data_misfit" -> const std::vector<DataMisfit>*.
- `ModelPtr build_implicit_model(const desc::Description& d, const BuildInputs& in, BuildLog& log);`  
  Build an implicit model (also available as the "implicit-rbf" structure-builder plugin).

## include/stratonix/engines/structure.hpp

- `(file)`  
  Unfaulted structure: stratigraphic column, fold primitives, imported surfaces with isochore stacking, and the well-correction field. z_h(x, y) is the elevation of horizon h in the restored (unfaulted) frame.
- `struct FoldPrimitive`  
  A fold primitive. shape() is 1 at the crest and 0 at the edge; rim() is the rim-syncline shape (0..1).
- `static double bump(double t, double w);`  
  Raised-cosine bump g(t; w) = (1 + cos(pi t / w)) / 2 for |t| < w.
- `double contribution(std::size_t h, double x, double y) const;`  
  Contribution to horizon h at (x, y).
- `class Structure`  
  Unfaulted horizon functions.
- `Structure(const desc::Description& d, const BuildInputs& in, BuildLog& log);`  
  Build from a validated description and its input grids. Honours the reference well by construction and other control wells by a correction field (reported in the log).
- `double z(std::size_t h, double x, double y) const;`  
  Elevation of horizon h at (x, y) in the restored frame.
- `void z_all(double x, double y, double* out) const;`  
  All horizons at (x, y) (out has horizons() entries).
- `double correction(std::size_t h, double x, double y) const;`  
  Correction applied at a point (for reports).
- `const std::vector<double>& max_correction() const { return max_corr_; }`  
  Maximum |correction| at the wells' neighbourhood per horizon (reported).
- `const std::vector<double>& reference_depths() const { return ref_depth_; }`  
  Reference depths (positive down) at the reference location.

## include/stratonix/figures/canvas.hpp

- `(file)`  
  Device-independent figures: a display list of paths, text and images in points (1/72 inch), written to SVG (text kept as text), rasterised (PNG, TIFF) and placed in PPTX. The same display list feeds every format, so content is identical across formats and platforms.
- `struct Image`  
  RGBA image (row-major, top row first, 4 bytes per pixel, straight alpha).
- `class Figure`  
  A figure: size in points, origin top-left, y downwards.
- `const Image* own(Image img);`  
  Keep images alive with the figure.
- `void set_font_family(std::string f) { font_ = std::move(f); }`  
  Font family for all text of this figure: empty (Arial / Liberation Sans, the default) or "DejaVu Sans". Text widths for layout use the matching built-in metrics.
- `double text_width(const std::string& s, double size, bool bold = false);`  
  Text width in points from built-in sans-serif metrics (Helvetica/Arial-compatible advance widths), so layout is identical on every platform.
- `double text_width(const std::string& s, double size, bool bold, const std::string& family);`  
  Text width for a font family ("" = the default metrics above, "DejaVu Sans" = DejaVu Sans advance widths). Text is UTF-8; characters without a table entry count as 0.6 em.
- `std::string to_svg(const Figure& f, const std::string& title = {});`  
  SVG document (text kept as <text>, images embedded as PNG).
- `struct Raster`

- `std::string encode_png(const Raster& r, double dpi);`  
  PNG (RGB, 8 bits, pHYs set to dpi) and TIFF (RGB, LZW, 300 dpi, no alpha) encoders.
- `Raster decode_tiff_lzw_for_test(const std::string& tiff);`  
  Decoders used by tests and by readers.
- `struct Slide`  
  One 16:9 slide holding a picture, with title, caption and speaker notes.
- `class ZipWriter`  
  Minimal deterministic zip writer (deflate, fixed timestamps).

## include/stratonix/model/model.hpp

- `(file)`  
  The model interface every engine implements, and the flat-layers reference model. Every model, whatever builds it, answers the same questions: which unit and which fault block is at a point, what is the value of each horizon's scalar field there, and (through the representation layer) where its surfaces are. Sections, exports and checks use only this interface, so they work unchanged for the parametric engine (v1) and an implicit engine (v2).
- `enum class EvidenceBasis { Design, Interpreted };`  
  Evidence basis of a whole model, written into every exported file.
- `using BlockCode = std::uint64_t;`  
  Fault-block code: bit f set when the point is on the hanging-wall side of fault f.
- `struct FaultInfo`  
  Approximate plane and extent of a fault, used by extractors to locate its surface.
- `struct ModelInfo`  
  Description of a model, independent of the engine.
- `std::vector<std::string> provenance;`  
  Data the model was conditioned on, one line per input with its evidence class and source (empty for purely parametric models). Carried into export READMEs and packages.
- `struct DataMisfit`  
  Misfit of a data-conditioned model at one data point (capability "data_misfit" returns a const std::vector<DataMisfit>*).
- `enum EvalFields : unsigned { kEvalUnit = 1u, kEvalBlock = 2u, kEvalScalars = 4u, kEvalAll = 7u };`  
  Which fields evaluate() should fill.
- `struct EvalResult`  
  Results of evaluate(), structure of arrays. scalar is horizon-major: scalar[h * n + i].
- `struct FaultEval`  
  Results of evaluate_fault().
- `class Model`  
  The model interface. Implementations are immutable after construction; all methods are thread-safe and write only to caller-owned outputs.
- `virtual void evaluate(std::span<const Vec3> pts, unsigned fields, EvalResult& out) const = 0;`  
  Evaluate unit index, block code and/or horizon scalar fields at points. Scalar convention: zero on the horizon, positive above it, approximately metres nearby.
- `virtual void scalar_in_block(std::span<const Vec3> pts, BlockCode block, int horizon, std::span<double> out) const = 0;`  
  Scalar field of one horizon as seen from a given fault block (extended beyond the block).
- `virtual void evaluate_fault(int fault, std::span<const Vec3> pts, FaultEval& out) const = 0;`  
  Distance to, extent coordinate on, and displacement of fault `fault` at points.
- `virtual void restore(std::span<const Vec3> pts, std::span<Vec3> out) const = 0;`  
  Positions in the restored (unfaulted) frame.
- `virtual const void* capability(std::string_view name) const { (void)name; return nullptr; }`  
  Optional engine-specific capability by name (nullptr if not provided).
- `class FlatLayersModel final : public Model`  
  Reference implementation: flat, horizontal, unfaulted layers. It is the simplest model that passes the interface suite, and documents the expected behaviour of every call.
- `FlatLayersModel(ModelInfo info, std::vector<double> horizon_z);`  
  horizon_z: elevations of the horizons, top to base (strictly decreasing).
- `inline int unit_from_scalars(const double* s, std::size_t stride, std::size_t nh)`  
  Unit index from horizon scalars at one point: the number of horizons the point lies below.

## include/stratonix/model/model_suite.hpp

- `(file)`  
  Interface conformance suite. Every engine must pass it.
- `SuiteReport run_model_suite(const Model& m, const SuiteOptions& opt = {});`  
  Run the interface suite against a model: S1 info is consistent (names, units tile horizons, domain valid, faults <= 64) S2 evaluate fills exactly the requested fields with the right sizes S3 unit index agrees with the horizon scalars (unit = number of horizons the point is below) S4 scalars are ordered: s_0 <= s_1 <= ... (a point is never further above a shallower horizon than a deeper one: no crossing) S5 scalar_in_block equals evaluate's scalar for points in that block S6 block code bit f agrees with the sign of evaluate_fault distance S7 results are identical in single and multi-threaded evaluation and in any batch split S8 restore leaves points of the fixed block (if any) unmoved and keeps array sizes S9 scalar decreases downward along verticals inside a block (monotone in z)

## include/stratonix/repr/repr.hpp

- `(file)`  
  Representations derived from any Model by evaluation only: horizon grids (per block and faulted with gaps), fault meshes, cut-off lines, throw tables, well intersections, sections, voxel grids and closure analysis. Each kernel has a reference implementation (plain, robust, slow). Where an optimised version exists it is selected by optimised_kernels() and must match the reference in parity tests.
- `BlockList list_blocks(const Model& m, std::size_t n = 48, std::size_t nz = 48);`  
  Sample the domain on an n x n x nz lattice and list the block codes present.
- `Grid2D horizon_grid_block(const Model& m, int horizon, BlockCode block, const GridSpec& g, double margin = 2000);`  
  Root of a horizon's scalar along verticals, as seen from one block (extended beyond it). Reference: bisection. Optimised: bracketed secant (Illinois). NaN if no root within the domain's elevation range extended by `margin`.
- `FaultedSurface horizon_grid_faulted(const Model& m, int horizon, const GridSpec& g);`  
  Faulted horizon surface with fault gaps. Reference: candidate blocks from dense sampling of each column. Optimised: block iteration from the per-block root. Parity tested.
- `FaultSurface fault_surface(const Model& m, int fault, double spacing, double extend = 0.0);`  
  Fault surface located by root-finding the fault distance along the approximate normal. `extend` enlarges the lattice beyond the tip line (fraction of the extent) so callers can sample just outside it; the mesh always covers only the region inside the tip line.
- `std::vector<Polyline> fault_sticks(const FaultSurface& fs, double spacing);`  
  Fault sticks: polylines down dip at a strike spacing, inside the tip line.
- `std::vector<CutoffLine> cutoff_lines(const Model& m, const FaultSurface& fs, int horizon, double eps = 0.25);`  
  Hanging-wall and footwall cut-off lines of a horizon on a fault (eps: offset from the plane).
- `std::vector<double> scalar_jumps(const Model& m, const std::vector<Vec3>& pts, const Vec3& normal, double eps = 0.25);`  
  Jump of each horizon's scalar across a surface at points with the given normal: the hanging-wall value minus the footwall value, each extrapolated linearly to the point from samples at eps and 2*eps on its side (exact for smooth linear fields). Result: [h * n + i].
- `std::vector<WellTop> well_intersections(const Model& m, const WellPath& w, double step = 2.0);`  
  Horizon crossings along a well path (handles fault crossings: a horizon top is recorded only where the scalar changes sign inside one block).
- `Closure closure_analysis(const Grid2D& z, bool faults_seal);`  
  Structural closure of a surface (elevation grid, NaN = gap). With faults_seal, gaps are barriers; otherwise reaching a gap counts as spilling.
- `TriMesh grid_to_mesh(const Grid2D& g);`  
  Triangulated surface from a grid: two triangles per fully defined cell, one where exactly three corners are defined; nothing across gaps. Vertices only at defined nodes.
- `std::vector<Polyline> contour_lines(const Grid2D& g, double level);`  
  Contour lines of a grid at a level (marching squares; NaN cells skipped).
